# Font Zoom

Font Zoom lets you change the font size of your notes in Obsidian by pinching with two fingers, just like zooming on a photo.

It is designed for mobile. Pinch outwards to make the text larger, or pinch inwards to make it smaller. Only the writing area changes, so Obsidian's menus, toolbars, and sidebars stay the same size.

## Features

- Pinch to zoom the text in both the editor and reading view
- Affects note text only, not the app interface
- Remembers your chosen size between sessions
- Shows the current font size while you pinch
- Adjustable minimum and maximum font size in settings
- A command and a settings button to reset to your normal font size

## Usage

1. Open any note.
2. Place two fingers on the note and pinch in or out.
3. To go back to your usual size, run the **Reset note font size** command, or press **Reset** in the plugin settings.

## Settings

- **Minimum font size**: the smallest size the pinch gesture can reach.
- **Maximum font size**: the largest size the pinch gesture can reach.
- **Reset font size**: returns to your normal Obsidian font size.
